# OnePlus TV (model D00, codename Dubai, MediaTek mt5867), Android TV 11 (not Google TV), India,
# build RTM1.210315.027 (incremental 2303030058, security patch 2023-01-05).
# System version on the About screen: BOVC601RIN04S01110V1.14.0T2303030058.
# examples/oneplus-tv-dubai/ is the same hardware on its Google TV 14 firmware; this list is the
# Android TV 11 firmware, with the classic Android TV home.
# Live TV app: com.heytap.tv.livetv. Stock launcher: com.google.android.tvlauncher.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/oneplus-tv-dubai-atv11/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/oneplus-tv-dubai-atv11/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Network ADB: there is no Network/ADB or Wireless debugging toggle. USB debugging alone opens port
# 5555, and switching it off closes it again (checked with tools/adb-closed.py, before and after a reboot).
#
# Already disabled at the factory, before any cleanup: com.heytap.olink (OnePlus Connect) and
# com.oneplus.tv.remote (OnePlus phone-remote service). The shell may not change com.heytap.olink
# ("Shell cannot change component state"), so neither is listed.
#
# Kept on purpose: Google Assistant (com.google.android.katniss), Chromecast
# (com.google.android.apps.mediashell), Miracast (com.heytap.optvmiracastservice, com.oplus.onet),
# the streaming apps, Play Store and Play Services. System updates come through Play Services here
# (com.google.android.gms/.update.SystemUpdatePanoActivity); there is no separate OnePlus updater.
# Left alone: com.heytap.oprcupgradeservice (remote firmware updates), com.oneplus.tv.android.account,
# com.heytap.tvapiservice and the factory apps (com.heytap.optvfactory, com.oneplus.tv.factory,
# mediatek.factorymenu.ui). android.autoinstalls.config.OnePlus is a Play auto-install stub, but
# tools/disable.sh skips it (its dumpsys shows no permission block), so it stays enabled.
#
# Remote: with this list and launcher/ as Home, Input, YouTube, Netflix, the Settings gear and Home
# all work without a key helper. Two buttons stop working:
# - The OnePlus button (KEYCODE_F2) opens Oxygen Play's page (com.oneplus.tv.intent.category.HOME),
#   so it does nothing once com.oneplus.tv.launcher is disabled.
# - The three-bars button sends KEYCODE_ASSIST (219) and nothing answers it once the stock launcher
#   is off. settings_key_keycodes 219 with HOME_KEY_SERVICE=1 opened Settings only on a long press,
#   and with the helper bound a held Volume Up stepped once instead of ramping, so it was left unmapped.
#
# Status: applied 2026-10-30 on one TV in five batches with a screenshot after each (the last two lines
# after launcher/ took Home), then rebooted twice with every entry still disabled. Home, the remote
# buttons and streaming apps checked the same day; not yet lived with for several days.
